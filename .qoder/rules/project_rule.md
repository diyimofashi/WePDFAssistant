系统环境：
1、编码环境：Windows
2、开发工具：Visual Studio Code
编码要求：
1、必须保证代码完整可运行，不得出现简略实现或todo等情况。
2、不要出现无用冗余的代码和注释。
3、代码和注释要清晰易懂，避免冗余。
4、代码要简洁明了，代码规范与风格要与项目保持一致。
5、请禁用print语句，除非必要。日志统一用picologging。
6、代码实现一定要注意性能，避免无用的计算和资源占用。
7、一个方法只做一件事，避免方法过长和复杂。
8、方法参数要少而精，避免方法参数过多导致方法职责不清。
9、每个文件只做一件事，避免文件过大和复杂。
测试策略
1、如需写测试代码，请将测试用的文件放在test目录。
