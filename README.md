# 极灵PDF (AuroraPDF)

一个功能强大、性能卓越的PDF文档处理工具。采用模块化设计,界面美观现代,支持PDF查看、编辑、OCR识别、条码处理、插件扩展等高级功能。

## 🎯 项目特色

- **模块化架构**：清晰的分层设计,采用混入类(Mixin)模式,便于维护和扩展
- **美观界面**：现代化UI设计,图标化操作,用户体验优秀
- **高性能优化**：异步加载、虚拟滚动、智能缓存,流畅处理大文件
- **插件系统**：支持OCR、条码、上传、下载等多种插件扩展
- **智能功能**：OCR文字识别、条码自动拆分、可搜索PDF生成等
- **安全可靠**：完整的撤销/重做机制,操作历史记录

## 🚀 快速开始

### 方法一：一键启动(推荐)

直接双击 `run.bat` 文件即可启动应用。

### 方法二：手动启动

1. 创建虚拟环境：
```bash
python -m venv pypdf
```

2. 激活虚拟环境：
```bash
pypdf\Scripts\activate
```

3. 安装依赖：
```bash
pip install -r requirements.txt
```

4. 运行应用：
```bash
python start.py
```

## 📚 核心功能详解

### 1. 文件管理功能

#### 1.1 文件打开
- **单文件打开**：支持PDF文件打开,支持密码保护的PDF文件
- **多图片打开**：支持同时打开多张图片文件(jpg, jpeg, png, bmp, gif, tiff, tif, webp, ico)
- **图片目录打开**：一键打开整个目录中的所有图片
- **远程文件打开**：支持从远程服务器下载并打开PDF文件
- **异步加载**：后台线程加载,实时显示进度,UI无卡顿

#### 1.2 文件保存
- **普通保存**：保存当前文档(使用原文件名)
- **另存为**：将文档保存到指定位置
- **加密保存**：设置密码保存,保护文档安全
- **加密另存为**：另存为加密PDF文件

#### 1.3 文件操作
- **导入图片**：将图片导入到当前PDF文档
- **从目录导入图片**：从指定目录批量导入图片
- **PDF转图片**：将PDF文档的每一页转换为图片
- **PDF分割**：支持多种分割方式(单页、范围、分组、书签、条码)

### 2. 页面编辑功能

#### 2.1 基础编辑
- **页面插入**：在指定位置插入新页面
- **页面删除**：删除不需要的页面
- **页面复制**：复制页面到指定位置
- **页面旋转**：支持90度旋转页面
- **撤销/重做**：完整的操作历史管理

#### 2.2 高级编辑
- **批量操作**：支持批量删除、批量旋转等操作
- **操作历史**：记录所有编辑操作,可随时回溯
- **变更提醒**：未保存的更改会有明确提示

### 3. OCR识别功能

#### 3.1 OCR识别
- **单页OCR**：对当前页面执行OCR识别
- **全文档OCR**：对全部页面批量执行OCR识别
- **截图OCR**：截图选区OCR识别功能(快捷键 Alt+S)
- **可搜索PDF**：生成包含OCR文本层的可搜索PDF

#### 3.2 OCR插件系统
- **多引擎支持**：支持RapidOCR、Azure Vision OCR等多种OCR引擎
- **插件化架构**：易于扩展新的OCR引擎
- **配置灵活**：可通过设置对话框调整OCR参数
- **性能优化**：支持并发识别,大幅提升批量处理速度

#### 3.3 OCR文本层
- **高亮显示**：OCR文本层可高亮显示,方便查看识别结果
- **调试模式**：OCR文本层高亮模式,可视化管理识别结果
- **自动适配**：OCR文本层随缩放比例自动调整

### 4. 条码处理功能

#### 4.1 条码检测
- **多种条码类型支持**：
  - 一维码：CODE128、CODE39、CODE93、CODABAR、EAN13、EAN8、EAN2、EAN5、UPCA、UPCE、DATABAR、I25、ISBN10、ISBN13
  - 二维码：QRCODE、PDF417、SQCODE
  - 复合码：COMPOSITE

#### 4.2 条码分割
- **自动分割**：根据条码自动分割PDF文档
- **分割预览**：预览分割结果,确认后再执行
- **过滤规则**：支持设置条码过滤规则,只分割包含特定条码的页面
- **插件支持**：支持条码检测插件扩展

#### 4.3 条码插件系统
- **插件化架构**：易于扩展新的条码检测算法
- **灵活配置**：支持设置条码类型、分割规则等参数

### 5. 视图控制功能

#### 5.1 缩放控制
- **放大/缩小**：逐步缩放(快捷键 Ctrl++ / Ctrl+-)
- **适应宽度**：自动调整缩放比例以适应窗口宽度
- **适应高度**：自动调整缩放比例以适应窗口高度
- **适应容器**：同时适应窗口宽度和高度
- **实际尺寸**：显示原始尺寸(100%)
- **预设比例**：支持25%、50%、75%、100%、125%、150%、200%等预设比例

#### 5.2 页面导航
- **上一页/下一页**：快速翻页(快捷键 PgUp / PgDown)
- **跳转到指定页**：直接跳转到指定页码
- **滚动导航**：通过滚动条或鼠标滚轮导航

#### 5.3 缩略图功能
- **智能缩略图**：显示所有页面缩略图
- **点击跳转**：点击缩略图快速跳转到对应页面
- **延迟加载**：按需生成缩略图,提升性能

- **显示/隐藏**：可随时切换缩略图面板

### 6. 搜索功能

#### 6.1 文本搜索
- **文本搜索**：在PDF中搜索指定文本(快捷键 Ctrl+F)
- **区分大小写**：支持区分大小写的搜索
- **全词匹配**：支持全词匹配搜索
- **OCR文本搜索**：支持在OCR识别的文本中搜索

#### 6.2 搜索结果

## 💡 使用技巧

### 文件操作
1. **快速打开文件**：使用快捷键 `Ctrl+O` 或点击工具栏的打开按钮
2. **另存为功能**：使用 `Ctrl+Shift+S` 或工具栏按钮,会使用当前文件名作为默认文件名
3. **加密保存**：在保存时可以设置密码,保护文档安全
4. **批量打开图片**：使用 `Ctrl+Shift+O` 可同时打开多张图片

### 视图操作
1. **缩略图导航**：左侧缩略图面板可直接点击跳转到指定页面
2. **缩放快捷键**：使用 `Ctrl++` 放大,`Ctrl+-` 缩小
3. **视图适配**：工具栏提供适应宽度、适应高度、适应容器等功能
4. **鼠标滚轮**：使用鼠标滚轮快速翻页

### 搜索功能
1. **快速搜索**：使用 `Ctrl+F` 搜索文本
2. **搜索导航**：搜索结果可快速定位,支持下一个/上一个匹配
3. **OCR文本搜索**：搜索会包含OCR识别的文本

### OCR功能
1. **单页OCR**：对当前页面执行OCR识别
2. **批量OCR**：对全部页面批量执行OCR识别
3. **截图OCR**：使用 `Alt+S` 快捷键启动截图OCR模式
4. **可搜索PDF**：生成包含OCR文本层的可搜索PDF,可全文检索
5. **OCR高亮**：开启OCR文本层高亮模式查看识别结果

### 条码功能
1. **条码拆分**：使用工具栏的"条码拆分"按钮,可按条码自动分割PDF
2. **条码检测**：支持多种条码类型,可设置过滤规则
3. **预览结果**：分割前可预览结果,确认后再执行

### 上传下载
1. **文档上传**：使用工具栏的"上传"按钮,可将当前文档上传到远程服务器
2. **远程下载**：使用菜单栏的"下载"功能,可下载远程PDF文件
3. **插件配置**：可通过设置对话框配置服务器参数

### AI助手
1. **PDF问答**：AI助手可以回答关于PDF内容的问题
2. **翻译功能**：可以翻译PDF中的文本内容
3. **内容总结**：可以自动总结PDF的主要内容

### 性能优化
1. **大文件处理**：虚拟滚动技术支持流畅浏览1000+页的PDF
2. **缓存优化**：智能缓存提供85%+的命中率
3. **内存监控**：状态栏显示实时内存使用情况

## 🐛 问题反馈

如果在使用过程中遇到问题,请检查：

1. 虚拟环境是否正确激活
2. 依赖包是否完整安装
3. 系统是否支持PyQt5
4. PDF文件是否损坏或加密
5. 插件配置是否正确
6. 查看日志文件 `logs/` 目录了解详细错误信息
