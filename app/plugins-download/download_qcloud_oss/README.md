***REMOVED*** COS 下载插件

使用腾讯云对象存储（COS）下载文件。

## 功能特性

- 支持从腾讯云 COS 下载文件
- 支持查看 COS 存储桶中的文件列表
- 支持重试机制
- 支持自定义路径前缀

## 配置说明

### 局部配置

- **地域**：选择存储桶所在地域（如：ap-guangzhou）
- **存储桶名称**：COS 存储桶名称（Bucket Name）
- **Secret ID**：腾讯云 API 密钥的 Secret ID
- **Secret Key**：腾讯云 API 密钥的 Secret Key
- **APP ID**：腾讯云账户的 APP ID（可选，旧版 API 使用）
- **路径前缀**：文件下载的路径前缀（如：uploads/）

### 全局配置

- **下载超时时间**：下载超时时间（秒）
- **最大重试次数**：下载失败时的重试次数

## 使用方法

1. 在腾讯云控制台创建存储桶
2. 获取访问密钥（Secret ID 和 Secret Key）
3. 在下载插件设置中配置上述信息
4. 点击"查看文件列表"按钮浏览远程文件
5. 选择文件并点击"打开"按钮下载并查看文件

## API 密钥获取

访问腾讯云控制台的[访问管理](https://console.cloud.tencent.com/cam/capi)页面创建 API 密钥。
