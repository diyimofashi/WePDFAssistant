***REMOVED*** COS 上传插件

基于腾讯云对象存储（Cloud Object Storage, COS）的文件上传插件。

## 功能特点

- 基于腾讯云 COS SDK
- 支持大文件分块上传
- 支持断点续传（重试机制）
- 支持访问权限控制（私有/公共读/公共读写）
- 支持路径前缀，便于文件分类管理
- 支持多地域选择
- 支持文件和字节流两种上传方式

## 系统要求

### 安装依赖

```bash
pip install cos-python-sdk-v5
```

## 配置说明

### 必填配置项

1. **存储桶名称（Bucket Name）**
   - 腾讯云 COS 存储桶的名称
   - 在腾讯云控制台创建存储桶后获得

2. **Secret ID**
   - 腾讯云 API 密钥的 Secret ID
   - 从腾讯云访问管理 -> 访问密钥中获取

3. **Secret Key**
   - 腾讯云 API 密钥的 Secret Key
   - 从腾讯云访问管理 -> 访问密钥中获取

### 可选配置项

1. **地域（Region）**
   - 存储桶所在地域
   - 默认：广州（华南）
   - 支持地域：北京、成都、广州、上海、南京、香港、新加坡、东京等

2. **APP ID**
   - 腾讯云账户的 APP ID
   - 仅旧版 API 需要，新版 SDK 可选

3. **路径前缀（Path Prefix）**
   - 文件上传的路径前缀
   - 例如：`uploads/` 会在存储桶中创建 `uploads/` 子目录
   - 留空则直接上传到存储桶根目录

4. **访问权限（ACL）**
   - 文件的访问控制列表
   - 选项：
     - `private` - 私有（默认）
     - `public-read` - 公共读
     - `public-read-write` - 公共读写

5. **超时时间（Timeout）**
   - 上传操作的超时时间（秒）
   - 默认：300秒

6. **最大重试次数（Max Retries）**
   - 上传失败时的重试次数
   - 默认：3次

7. **分块大小（Chunk Size）**
   - 分块上传的大小（字节）
   - 默认：1MB

## 使用说明

1. 在腾讯云控制台创建 COS 存储桶
2. 获取 API 密钥（Secret ID 和 Secret Key）
3. 将插件目录放置在应用的 `app/plugins-upload/` 目录下
4. 在应用的上传设置中选择 "腾讯云 COS Upload" 插件
5. 配置必填项（存储桶名称、Secret ID、Secret Key）
6. 根据需要配置可选项
7. 开始上传文件

## 上传结果

上传成功后返回的 `data` 字段包含：
- `key`: 文件在 COS 中的完整路径
- `bucket`: 存储桶名称
- `region`: 所在地域
- `size`: 文件大小（字节）
- `url`: 文件的访问 URL
- `etag`: 文件的 ETag 值

## 文件访问 URL

- **私有文件**：需要临时签名 URL 或通过 COS 控制台访问
- **公共文件**：直接通过返回的 URL 访问

- 存储容量（GB/月）
- 请求次数（万次/月）
- 流量（GB/月）

## 安全建议

1. 不要将 Secret ID 和 Secret Key 硬编码在代码中
2. 使用子账号进行权限控制，避免使用主账号密钥
3. 设置合理的访问权限，避免敏感文件公开访问
4. 定期轮换 API 密钥
5. 启用存储桶的日志记录功能

## 故障排查

### 常见错误

**初始化错误**
- 检查 Secret ID 和 Secret Key 是否正确
- 检查存储桶名称是否正确
- 检查网络连接是否正常

**上传失败**
- 检查存储桶访问权限
- 检查是否有足够的配额
- 检查文件大小是否超过限制

**连接超时**
- 增加 timeout 配置值
- 检查防火墙设置
