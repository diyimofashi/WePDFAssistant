# 文件历史记录面板 - 左右分栏布局

## 功能概述

文件历史记录面板采用左右分栏布局，提供便捷的文件历史记录访问功能。

## UI布局

### 左侧 - 目录树

左侧显示文件分类树，包含以下三个主要部分：

1. **⏰ 最近项目**
   - 显示所有最近打开的文件，按打开时间降序排列
   - 不进行分类，方便快速访问最近使用的文件

2. **📂 所有目录**
   - 按目录名称分组显示所有文件
   - 展开每个分类可以看到该目录下的文件数量
   - 自动根据目录路径智能分类

3. **📅 按月份归档**
   - 按文件的最后打开时间归档
   - 显示格式为 YYYY-MM（如 2026-02）
   - 方便按时间查找历史文件

### 右侧 - 文件列表

右侧显示当前选中目录下的文件列表，每个文件卡片包含：

- **缩略图**（120x160像素）
  - PDF第一页的缩略图预览
  - 异步加载，不阻塞UI
  - 支持缓存机制

- **文件名**
  - 显示完整的文件名
  - 超长文件名自动截断

- **最后打开时间**
  - 显示相对时间（如"刚刚"、"5分钟前"）
  - 超过一周显示具体日期

- **页数**
  - 显示PDF总页数

## 使用方式

### 打开历史记录面板

1. 通过菜单：`视图 > 历史记录面板`
2. 通过工具栏：点击"📜 历史记录"按钮

### 访问历史文件

1. 在左侧目录树中选择一个分类
2. 右侧自动加载该分类下的文件
3. 双击文件卡片打开文件

### 右键菜单功能

**目录树右键菜单：**
- 🔄 刷新：刷新当前分类的文件列表
- 🗑️ 清除：清除最近文件或指定分类

**文件右键菜单：**
- 📂 打开文件：打开选中的PDF文件
- 🔍 在资源管理器中显示：打开文件所在目录
- 🗑️ 从历史中移除：从历史记录中删除该文件

## 自动分类规则

系统根据以下规则自动对文件进行分类：

1. **用户自定义映射**：优先使用用户在"管理分类"中设置的目录到分类的映射
2. **关键词匹配**：根据目录名匹配预设关键词（如"工作"、"学习"、"书籍"等）
3. **目录名**：使用目录名作为分类名称
4. **未分类**：无法匹配的归为"未分类"

## 管理分类

点击面板底部的"⚙️ 管理分类"按钮可以：
- 添加自定义目录到分类的映射
- 编辑现有映射
- 删除映射

## 数据存储

所有历史记录数据保存在配置文件中：
- 文件路径：`config/app_settings.json`
- 数据结构：
  ```json
  {
    "file_history": {
      "recent_files": [],
      "categories": {},
      "category_mapping": {},
      "max_recent": 20,
      "max_per_category": 10
    }
  }
  ```

## 性能优化

1. **异步缩略图生成**：缩略图在后台线程生成，不影响UI响应
2. **缩略图缓存**：已生成的缩略图会被缓存，避免重复生成
3. **延迟加载**：只在需要时才生成缩略图
4. **文件存在性检查**：自动过滤已不存在的文件

## 注意事项

1. 临时文件（在TEMP目录下或文件名以temp_/~开头）不会被记录
2. 每个分类最多保存10个文件
3. 最近项目最多保存20个文件
4. 重复打开文件会更新其打开时间并移动到列表开头
