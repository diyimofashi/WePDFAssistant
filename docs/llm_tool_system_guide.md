# LLM工具系统使用指南

## 概述

LLM工具系统让您可以通过自然语言对话来操作PDF文档。系统会自动理解您的意图，并调用相应的工具来完成任务。

## 支持的功能

### 1. 打开PDF文档
**对话示例：**
- "帮我打开一个PDF文档"
- "打开文档看看"

**操作流程：**
1. 系统识别到需要打开PDF
2. 弹出文件选择对话框
3. 您选择要打开的PDF文件
4. 系统打开文档并返回结果

### 2. 拆分PDF文档
**对话示例：**
- "把这个文档拆分一下"
- "按页数拆分PDF"

**操作流程：**
1. 系统识别到需要拆分PDF
2. 弹出拆分配置对话框，让您选择拆分方式：
   - 按页数拆分
   - 按范围拆分
   - 按书签拆分
3. 您配置好拆分参数
4. 系统执行拆分并返回结果

### 3. OCR文字识别
**对话示例：**
- "对这份文档做OCR识别"
- "识别文档中的文字"

**操作流程：**
1. 系统识别到需要OCR识别
2. 可以指定识别语言（默认中英混合）
3. 可以指定识别的页面范围
4. 系统执行OCR并返回结果

### 4. 合并PDF文档
**对话示例：**
- "合并这些PDF文档"
- "把这几个文件合并成一个"

**操作流程：**
1. 系统识别到需要合并PDF
2. 您选择要合并的多个PDF文件
3. 指定输出文件路径
4. 系统执行合并并返回结果

### 5. 加密PDF文档
**对话示例：**
- "给这个文档加密"
- "添加密码保护"

**操作流程：**
1. 系统识别到需要加密PDF
2. 您输入密码
3. 系统执行加密并返回结果

## 使用技巧

### 清晰表达意图
- ✅ "帮我打开D盘的test.pdf"
- ✅ "把当前文档按每50页拆分"
- ✅ "识别第1到第10页的文字"

### 使用自然语言
- 系统能够理解中文自然语言
- 不需要记住具体的命令或参数
- 可以用多种方式表达相同的需求

### 参数补充
如果您的指令缺少必要参数，系统会：
1. 自动弹出相应的对话框
2. 提示您输入缺失的信息
3. 支持您取消操作

## 配置选项

您可以在 `app/config/llm_tools_config.json` 中配置：

### 工具启用/禁用
```json
{
  "tools": {
    "open_pdf": {
      "enabled": true
    },
    "split_pdf": {
      "enabled": true
    }
  }
}
```

### 用户确认设置
```json
{
  "tools": {
    "split_pdf": {
      "require_user_confirmation": true
    }
  }
}
```

### 默认参数
```json
{
  "tools": {
    "ocr_pdf": {
      "default_language": "chi_sim+eng"
    }
  }
}
```

## 注意事项

1. **安全性**：重要操作（如拆分、加密）默认需要用户确认
2. **参数记忆**：系统会记住您上次的选择，下次自动填充
3. **错误处理**：如果操作失败，系统会显示详细的错误信息
4. **取消操作**：在任何对话框中都可以点击"取消"来中止操作

## 扩展工具

如果需要添加新的工具，请参考 `app/core/llm/tools/pdf_tools.py` 中的示例，继承 `BaseTool` 类并实现必要的方法。
