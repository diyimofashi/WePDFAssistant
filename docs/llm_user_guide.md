# LLM插件系统使用指南

## 概述

PyPDF项目现已集成LLM(大语言模型)插件系统,用户可以通过与大模型对话来使用项目的所有功能。

## 功能特性

1. **多厂商支持**: 支持OpenAI、Claude、通义千问等多种LLM厂商
2. **插件化架构**: 各LLM插件完全独立、可拔插
3. **工具调用**: LLM可以主动调用PDF、OCR、条码等业务功能
4. **记忆系统**: 支持对话记忆,实现连续对话
5. **流式输出**: 支持流式响应,提升用户体验
6. **安全机制**: API密钥加密、速率限制、权限控制

## 快速开始

### 1. 配置LLM插件

1. 打开应用程序,点击菜单栏 `LLM` -> `设置`
2. 在"插件设置"选项卡中选择要使用的LLM插件(如OpenAI)
3. 输入API密钥和其他配置信息
4. 勾选"启用此插件"
5. 点击"保存"按钮

### 2. 开始对话

1. 点击菜单栏 `LLM` -> `对话`
2. 在对话框中选择LLM插件
3. 在输入框中输入您的问题
4. 点击"发送"按钮或按Enter键

## 支持的工具

LLM可以通过工具调用以下功能:

### PDF工具

- **pdf_extract_text**: 从PDF中提取文本
- **pdf_summary**: 生成PDF摘要
- **pdf_qa**: 基于PDF内容回答问题

### OCR工具

- **ocr_pdf**: 使用OCR识别PDF中的文本

### 条码工具

- **barcode_split**: 根据条码位置分割PDF

### 上传工具

- **upload_file**: 上传文件到远程服务器

### 下载工具

- **download_file**: 从远程服务器下载文件

## 配置说明

### 插件配置

每个LLM插件都需要以下配置:

- **API密钥**: 必填,用于身份验证
- **基础URL**: 可选,自定义API端点
- **默认模型**: 可选,指定使用的模型
- **最大Tokens**: 可选,限制输出长度
- **温度**: 可选,控制输出随机性(0-2)

### 记忆系统配置

- **存储后端**: 内存(in_memory)或文件(file)
- **存储路径**: 文件存储时的保存路径
- **最大记忆数**: 保存的记忆数量上限

### 聊天设置

- **流式输出**: 是否启用流式响应
- **最大历史记录**: 保存的对话历史数量
- **自动保存**: 是否自动保存对话
- **系统提示词**: LLM的系统提示词

### 安全设置

- **启用速率限制**: 是否启用API调用速率限制
- **每分钟最大调用次数**: API调用频率限制

## 菜单说明

LLM菜单包含以下选项:

- **对话**: 打开LLM对话窗口
- **设置**: 打开LLM设置对话框
- **插件**: 选择要使用的LLM插件
- **性能报告**: 查看LLM调用性能统计

## 性能监控

点击 `LLM` -> `性能报告` 可以查看:

- 总调用次数
- 总Token数
- 总耗时
- 总错误数
- 缓存使用情况
- 各插件的详细统计信息

## 注意事项

1. **API密钥安全**: 请妥善保管您的API密钥,不要泄露给他人
2. **网络连接**: 使用LLM功能需要网络连接
3. **Token限制**: 注意Token使用量,避免超出API配额
4. **响应时间**: 首次对话可能需要较长时间,后续会逐渐加快

## 故障排除

### 问题1: 无法连接到LLM服务

**解决方案**:
- 检查网络连接
- 确认API密钥是否正确
- 检查API端点URL是否正确

### 问题2: 对话响应很慢

**解决方案**:
- 检查网络连接质量
- 尝试使用更快的模型
- 减少对话历史记录数量

### 问题3: 工具调用失败

**解决方案**:
- 检查文件路径是否正确
- 确认相关插件是否已加载
- 查看日志了解详细错误信息
