# PDF拆分功能使用指南

## 🎯 功能概述

极灵PDF的拆分功能提供了5种不同的PDF拆分模式，满足各种使用场景：

### 📋 拆分模式

#### 1. 📄 **单页拆分**
- **用途**: 将PDF的每一页保存为独立的PDF文件
- **适用场景**: 
  - 需要单独处理每一页内容
  - 提取特定页面进行归档
  - 将多页文档分发给不同人员

#### 2. 📑 **范围拆分**
- **用途**: 按照指定的页面范围进行拆分
- **语法支持**:
  - `1-5` - 拆分第1页到第5页
  - `8,10,12-15` - 拆分第8、10、12到15页
  - `20-` - 拆分第20页到末尾
- **适用场景**:
  - 提取特定章节
  - 分离合同的不同部分
  - 批量提取相关页面

#### 3. 📚 **分组拆分**
- **用途**: 按照固定的页数将PDF分组拆分
- **参数**: 每组的页数（1-100页）
- **适用场景**:
  - 将大型文档分解为可管理的小文件
  - 按章节大小分组（如每5页一组）
  - 便于网络传输和分享

#### 4. 📊 **章节拆分**
- **用途**: 根据PDF中的书签/目录自动拆分
- **要求**: PDF必须包含书签
- **适用场景**:
  - 拆分教科书的不同章节
  - 提取报告的各个部分
  - 分离论文的不同章节

#### 5. 🎯 **自定义拆分**
- **用途**: 手动选择页面组合进行拆分
- **功能**: （开发中）将支持可视化的页面选择
- **适用场景**:
  - 复杂的页面组合需求
  - 需要精确控制每个输出文件的内容

## 🚀 使用方法

### 📋 三步拆分流程

#### 🎯 **第一步：选择拆分规则**
1. 打开PDF文件
2. 点击菜单栏：`工具` → `✂️ 分割PDF`
3. 或点击工具栏的`✂️ 拆分`按钮
4. 在拆分规则对话框中：
   - 选择拆分模式（单页、范围、分组、章节、自定义）
   - 设置基础文件名
   - 配置模式特定参数
   - 点击"下一步" →

#### 📁 **第二步：选择保存目录**
1. 查看拆分配置摘要
2. 选择或创建输出目录
3. 确认配置无误
4. 点击"🚀 开始拆分"

#### 🔄 **第三步：查看拆分进度**
1. 实时显示拆分进度和状态
2. 可随时取消拆分操作
3. 完成后可选择打开输出目录查看结果

### 🎨 **用户界面特点**
- **向导式流程** - 清晰的三步操作流程
- **实时预览** - 每步都能看到配置摘要
- **智能检测** - 自动检测PDF书签状态
- **进度反馈** - 详细的进度条和状态信息
- **错误处理** - 友好的错误提示和解决建议

## 📝 参数说明

### 基础参数
- **基础文件名**: 输出文件的前缀名称
- **输出目录**: 拆分后文件的保存位置

### 模式特定参数

#### 范围拆分参数
```
1-5,8,10-15,20-
```
每行一个范围，支持多种格式组合。

#### 分组拆分参数
- **每组的页数**: 1-100页之间

#### 章节拆分参数
- 自动检测书签，无需额外参数

## 💡 使用技巧

### 1. 命名建议
使用有意义的文件名前缀：
- `合同_部分1` - 用于合同拆分
- `教材_第1章` - 用于教材拆分
- `报告_附件` - 用于报告拆分

### 2. 输出目录管理
建议创建专门的目录：
```
/
├── 原始PDF/
│   └── 完整文档.pdf
└── 拆分输出/
    ├── 单页拆分/
    ├── 章节拆分/
    └── 范围拆分/
```

### 3. 范围表达式高级用法
```
1-10      # 第1页到第10页
1,3,5     # 第1、3、5页
1-5,10-15 # 第1-5页和第10-15页
20-       # 第20页到末尾
-5        # 第1页到第5页
```

### 4. 性能优化建议
- **小文件**（<10页）: 使用单页拆分
- **中等文件**（10-100页）: 使用范围或分组拆分
- **大文件**（>100页）: 建议使用章节拆分或分组拆分

## 🛠️ 技术实现

### 核心组件
- **SplitManager**: 拆分功能管理器
- **SplitDialog**: 用户界面
- **SplitWorker**: 后台拆分线程

### 依赖库
- `PyMuPDF`: 书签读取和高级解析
- `PyQt5`: 用户界面

### 安全特性
- 多线程处理，避免界面冻结
- 错误处理和用户友好提示
- 自动创建输出目录
- 文件名安全处理（特殊字符替换）

## 🚨 注意事项

### 1. 文件要求
- PDF文件必须有效且完整
- 对于章节拆分，PDF应包含书签
- 确保有足够的磁盘空间

### 2. 性能考虑
- 大文件拆分可能需要较长时间
- 单页拆分会生成大量文件
- 建议使用SSD以提高处理速度

### 3. 兼容性
- 支持PDF 1.0 - 2.0格式
- 支持加密PDF（需要密码）
- 兼容各种PDF生成工具

## 🔧 故障排除

### 常见问题

**Q: 拆分后文件无法打开？**
A: 检查原始PDF是否损坏，确保有写入权限。

**Q: 拆分速度很慢？**
A: 大文件拆分需要时间，考虑使用分组拆分减少文件数量。

**Q: 章节拆分不工作？**
A: 检查PDF是否包含书签，可以使用PDF阅读器验证。

**Q: 范围表达式无效？**
A: 确保语法正确，页码范围不能超过总页数。

### 错误代码
- `E001`: PDF文件未打开
- `E002`: 输出目录无效
- `E003`: 页面范围错误
- `E004`: 书签不存在
- `E005`: 权限不足
