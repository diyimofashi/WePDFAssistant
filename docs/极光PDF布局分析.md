# 极光PDF布局分析与功能说明

## 1. 整体布局结构

### 主界面布局（从上到下）
```
┌─────────────────────────────────────────────────────────────┐
│ 顶部菜单栏 (Menu Bar)                                        │
├─────────────────────────────────────────────────────────────┤
│ 主工具栏 (Tool Bar) - 核心功能按钮                            │
├─────────────────────────────────────────────────────────────┤
│ 左侧边栏 (可折叠) │          PDF内容显示区域                   │
│ 页面缩略图导航   │                                          │
│ 书签目录         │                                          │
│ 属性面板         │                                          │
├─────────────────────────────────────────────────────────────┤
│ 底部状态栏 (Status Bar) - 文件信息/页码/缩放                │
└─────────────────────────────────────────────────────────────┘
```

## 2. 菜单栏功能详细说明

### 文件菜单 (File)
- **打开**: Ctrl+O - 打开PDF文件
- **保存**: Ctrl+S - 保存当前PDF（如果可编辑）
- **另存为**: Ctrl+Shift+S - 另存为PDF文件
- **打印**: Ctrl+P - 打印PDF文档
- **属性**: 查看PDF文档属性信息
- **退出**: Ctrl+Q - 退出应用程序

### 编辑菜单 (Edit)
- **撤销**: Ctrl+Z - 撤销操作
- **重做**: Ctrl+Y - 重做操作
- **选择**: 选择文本/图像
- **复制**: Ctrl+C - 复制选中内容
- **查找**: Ctrl+F - 在文档中查找文本

### 视图菜单 (View)
- **页面布局**: 单页/双页/连续页面显示
- **缩放**: 实际大小/适合宽度/适合页面
- **旋转**: 顺时针/逆时针旋转页面
- **全屏**: F11 - 全屏显示
- **工具栏**: 显示/隐藏不同工具栏

### 工具菜单 (Tools)
- **注释工具**: 高亮/下划线/批注
- **表单工具**: 填写PDF表单
- **测量工具**: 测量距离/面积
- **安全设置**: 密码保护/权限设置

### 帮助菜单 (Help)
- **帮助文档**: F1 - 打开帮助手册
- **关于**: 显示程序信息

## 3. 工具栏按钮功能说明

### 主要工具栏 (从左到右)
```
[打开] [保存] [打印] [放大] [缩小] [适合宽度] [适合页面] [上一页] [下一页] [页码输入框] [搜索框]
```

**具体功能说明：**

#### 文件操作组
- **📂 打开按钮**: 点击打开文件选择对话框，支持拖拽文件
- **💾 保存按钮**: 保存当前文档的修改
- **🖨️ 打印按钮**: 调用系统打印对话框

#### 缩放控制组
- **🔍 放大按钮**: 点击放大25%，支持滚轮缩放
- **🔎 缩小按钮**: 点击缩小25%，最小缩放到10%
- **📏 适合宽度**: 自动调整缩放使页面宽度适合窗口
- **📄 适合页面**: 自动调整缩放使整个页面适合窗口

#### 页面导航组
- **⬅️ 上一页**: 跳转到上一页，到达第一页时禁用
- **➡️ 下一页**: 跳转到下一页，到达最后一页时禁用
- **页码输入框**: 直接输入页码跳转，实时验证输入

#### 搜索功能
- **🔍 搜索框**: 输入关键词搜索，高亮显示匹配项

## 4. 侧边栏功能模块

### 页面缩略图导航
- 显示所有页面的缩略图
- 点击缩略图快速跳转到对应页面
- 支持拖拽重新排序页面
- 显示当前页面的指示器

### 书签目录面板
- 显示PDF内置的书签结构
- 支持展开/折叠目录层级
- 点击书签快速跳转

### 属性信息面板
- 显示文档属性：标题、作者、主题等
- 显示页面信息：尺寸、方向等
- 显示安全信息：加密状态、权限等

## 5. 状态栏信息显示

### 左侧状态区
- **文件信息**: 显示文件名和路径
- **页面信息**: "第 X 页 / 共 Y 页" 格式
- **缩放比例**: 显示当前缩放百分比

### 右侧状态区
- **文档状态**: 显示修改状态（已修改/未修改）
- **安全状态**: 显示加密/权限状态图标
- **加载进度**: 显示大文件加载进度

## 6. 交互设计特点

### 傻瓜式操作特性
1. **一键式操作**: 主要功能都提供工具栏按钮
2. **直观反馈**: 操作后立即有视觉反馈
3. **智能提示**: 鼠标悬停显示功能说明
4. **快捷键支持**: 常用操作支持键盘快捷键
5. **拖拽支持**: 支持文件拖拽打开

### 界面友好设计
1. **分组布局**: 相关功能按钮分组显示
2. **状态指示**: 明确显示当前操作状态
3. **渐进式显示**: 复杂功能逐步展开
4. **错误处理**: 友好的错误提示和恢复

## 7. 视觉设计规范

### 色彩方案
- **主色调**: 蓝色系 (#007acc)
- **辅助色**: 灰色系 (#666666)
- **强调色**: 绿色（成功）/红色（警告）
- **背景色**: 浅灰色/深色主题可选

### 图标设计
- 使用简洁的Material Design风格图标
- 图标大小统一为24x24像素
- 支持高分辨率显示

### 布局规范
- 按钮间距：8px
- 边距：16px
- 圆角半径：4px
- 字体大小：主标题16px，正文12px
